Главный секрет: Дизайн-токены вместо прилагательныхПрилагательные «красивый», «современный», «премиальный» нейросеть понимает очень абстрактно. Вместо них используйте дизайн-токены — конкретные значения визуальных параметров.Вместо этого (абстрактно):Передавайте это (конкретно/токены):Красивый темный стильPalette: Background: #0E1015, Surface: #171A21, Accent: #7C6CF2.Закругленные углыRadii: Controls: 8px, Cards: 12px.Хорошие отступыSpacing Base: 4px. Паддинги карточек: 16px, 24px.Современный шрифтTypography: Primary: Segoe UI Variable (if Windows) or Inter. Body: 14px.Легкая прозрачностьEffects: Overlay context: 80% opacity with backdrop-filter: blur(10px).Структура идеального запроса для дизайнаРазбивайте свой запрос на 5 четких блоков.1. Роль и КонтекстЗадайте модели профессиональную роль.«Действуй как ведущий UI/UX дизайнер современных AI-продуктов и опытный фронтенд-разработчик. Твоя задача — создать эстетичный, минималистичный и технически чистый интерфейс для...»2. Объект и ФункционалКоротко опишите, что это за элемент и как он работает.«Это компактный игровой оверлей-виджет для AI-ассистента. Он должен отображаться поверх окна игры в углу. Он должен быть компактным, не мешать обзору, появляться плавно при уведомлении и позволять развернуть полный текст ответа по клику.»3. Технический СтекУкажите языки и библиотеки.«Используй HTML5, CSS3 (без внешних библиотек)» ИЛИ «Используй React и Tailwind CSS» ИЛИ «Используй C# WPF (XAML) с библиотекой wpfui».4. Полная Визуальная Спецификация (Самый важный блок)Передайте дизайн-токены, описанные выше.Настроение: Минимализм, футуризм, спокойствие, премиальность.Цветовая палитра: Явные hex-коды для фона, поверхностей, акцентов, текста и состояний (Success/Warning/Error).Типографика: Названия шрифтов, размеры для заголовков и обычного текста, вес.Сетка и Отступы: Базовый шаг и паддинги элементов.Формы: Скругления углов.Эффекты: Тени, прозрачность, размытие фона (blur).5. Компоненты и СостоянияОпишите, какие элементы нужны и как они меняются.«Создай компоненты: NotificationToast, ExpandedAnswerPanel, QuickActionButton. Опиши их состояния: default, hover, active, thinking (анимация загрузки).»Примеры готовых запросовПример 1: React + Tailwind CSS (Современный веб)Act as a Senior Frontend Developer with strong UI/UX skills. Create a beautiful, minimalist login card component using React and Tailwind CSS.Visual Specification:Theme: Premium modern dark mode.Colors:Background: #0A0B10Card Surface: #14151FAccent: #3B82F6 (blue)Text: Primary #F3F4F6, Secondary #9CA3AFTypography: Use Inter font family via Google Fonts. Card Title: 20px Semibold. Body: 14px.Radii: Card corners: 16px. Buttons/Inputs: 8px.Spacing: Base step 4px. Card padding: 24px.Effects: Subtle background blur on inputs when focused. No aggressive glow.Components: Include fields for Email, Password (with visual toggle), "Forgot Password" link, and a full-width Primary Button. All inputs must have proper hover and focus states using the accent color.Пример 2: WPF (XAML) (Десктопное приложение Windows)Действуй как ведущий разработчик интерфейсов WPF (C#) и UX-дизайнер. Создай XAML-код для Главного окна настроек приложения. Дизайн должен быть родным для Windows 11.Визуальная спецификация:Стиль: Минимализм, стиль Windows 11 (Sun Valley), модульность.Цвета (Semantic Dark):App Background: #0E1015Card Surface: #171A21Accent: #7C6CF2 (фиолетовый Amethyst)Text Primary: #F4F5F7Типографика: Используй Segoe UI Variable. Page Title: 28px Semibold. Section Title: 16px Semibold. Body: 14px.Скругления: Карточки настроек: 12px. Контролы: 8px.Отступы: Отступы внутри карточек: 16px или 20px. Разрыв между карточками: 12px.Компоненты: Используй структуру NavigationView слева и ScrollViewer с модульными карточками настроек (Border с мягкой тенью) справа. Каждая карточка должна содержать Иконку, Заголовок, Описание и элемент управления (например, ToggleSwitch, Slider или ComboBox). Все контролы должны иметь стили Windows 11.
