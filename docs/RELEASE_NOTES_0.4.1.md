# GTA RP Assistant 0.4.1

Дата сборки: 15 августа 2026 года.

## Главное

- Полностью светлая дизайн-система для основного окна и обоих оверлеев.
- Новая иконка и отдельная идентичность процесса, панели задач, tray и ярлыков Windows.
- Автономный русский GigaAM v2 + sherpa-onnx STT включён в self-contained Windows x64 пакет; Windows Speech, LM Studio, Python и отдельный .NET для распознавания не требуются.
- Микрофон запускается автоматически при разрешённой голосовой активации. Фраза по умолчанию: «Лаберти, слушай».
- Пауза 1,1 секунды завершает реплику; речь, возобновлённая до тайм-аута, продолжает тот же вопрос. После ответа действует 12-секундное окно голосового уточнения без повторения имени.
- Локальная история чатов включена по умолчанию и доступна в шапке ассистента.
- Введённый текст очищается после отправки; каждое сообщение можно скопировать.
- Ассистент отвечает от первого лица и объясняет собственные функции, память и настройку.
- Экраны «Поведение» и «Приватность» переписаны понятным языком.

## Установка

- Основной ZIP и STT-host self-contained.
- Установщик проверяет SHA-256 архива и файлов STT, безопасные пути, язык, архитектуру и свободное место.
- Поддержаны произвольный безопасный путь, ярлыки, автозапуск, Installed Apps, rollback и uninstall.
- Проверенная установка: `E:\Code\GTA RP Assistant`; исходники: `E:\Code\LAB_AI (GTA5RP)`.

## Данные и приватность

- Чаты хранятся локально в `assistant-data.db`; постоянную историю можно отключить.
- Настройки и базы находятся в `%LocalAppData%\GtaRpAssistant`.
- Аудио и снимки экрана не сохраняются как файлы.
- Облачная передача запрещена без явного разрешения.
- API-ключи защищены DPAPI CurrentUser и не хранятся в `settings.json`.
