# Anti-cheat boundaries

Приложение не внедряется в GTA, не читает память процесса, не создаёт ввод, не сканирует сеть и не определяет FPS игры. Детектор использует стандартный список процессов и main window без прав администратора.

Process-specific audio loopback использует официальный Windows application-loopback API. Он только получает звук выбранного process tree и не меняет процесс GTA.

Vision запускается исключительно по `Ctrl+Alt+S`: делается один снимок видимой области обнаруженного окна, показывается preview, требуется подтверждение, после ответа данные удаляются из памяти. Нет постоянного захвата, анализа кадров, боевого анализа или подсветки объектов.

TTS воспроизводит текст только после ручного голосового запроса `Ctrl+Alt+A` и не генерирует игровой ввод.
