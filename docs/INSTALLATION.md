# Установка, обновление и откат

Release gate создаёт в `artifacts/release` self-contained portable ZIP, `.zip.sha256`, manifest и три user-scope скрипта. Поддерживаются Windows 10/11 x64; отдельно устанавливать .NET не нужно. По умолчанию приложение устанавливается в `%LocalAppData%\Programs\GtaRpAssistant`; права администратора не требуются.

## Установка и обновление

```powershell
.\install.ps1 -Package .\GtaRpAssistant-0.2.0-win-x64.zip
```

Установщик создаёт ярлыки рабочего стола и меню «Пуск» с фирменной иконкой, регистрирует GTA RP Assistant в списке установленных приложений Windows и сохраняет предыдущую версию для отката. Для запуска сразу после установки и автозапуска при входе пользователя:

```powershell
.\install.ps1 -Package .\GtaRpAssistant-0.2.0-win-x64.zip -StartAfterInstall -StartWithWindows
```

Автозапуск остаётся явным выбором и позднее может быть изменён в настройках приложения. Процесс использует стабильный Windows AppUserModelID `LABAI.GtaRpAssistant`, поэтому окно, ярлык, трей и карточка приложения в Диспетчере задач группируются отдельно от локальных AI/STT worker-процессов.

Скрипт проверяет соседний `.zip.sha256`, распаковывает пакет во временную папку, проверяет entry point и только затем заменяет установленную версию. При обновлении предыдущая версия переносится в каталог `.rollback`. Повторный запуск той же команды выполняет upgrade.

Для установки без ярлыков:

```powershell
.\install.ps1 -Package .\GtaRpAssistant-0.2.0-win-x64.zip -NoShortcuts
```

Для любого другого пользовательского каталога, включая другой диск и путь с пробелами:

```powershell
.\install.ps1 -Package .\GtaRpAssistant-0.2.0-win-x64.zip -InstallRoot "D:\Portable Apps\GTA RP Assistant"
```

Тот же `-InstallRoot` передавайте в `rollback.ps1` и `uninstall.ps1`. Место установки GTA и LM Studio не связано с местом установки ассистента. Нестандартные пути LM Studio выбираются внутри приложения: **AI и модели → Расширенные настройки**.

По умолчанию `eng\build.ps1` создаёт self-contained пакет и автоматически проверяет установку/запуск из нестандартной папки. Только для служебной компактной сборки, требующей установленный .NET 8 Desktop Runtime, используйте `-FrameworkDependent`.

## Откат и удаление

```powershell
.\rollback.ps1
.\uninstall.ps1
```

`rollback.ps1` работает только при наличии предыдущей версии. `uninstall.ps1 -KeepRollback` сохраняет backup. Все операции проверяют целевые пути и отказываются рекурсивно удалять корень диска или неожиданный соседний каталог.

## Ограничение доверия

SHA-256 обнаруживает повреждение или несогласованность файлов, но не подтверждает автора. Текущий portable-релиз и PowerShell-скрипты ещё не подписаны. До появления code-signing сертификата release следует получать только из доверенного канала и сверять опубликованный checksum отдельно от архива.
