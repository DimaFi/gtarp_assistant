# Приватность

Телеметрия отсутствует. Аудиофайлы и снимки на диск не записываются. Временный transcript-контекст очищается по TTL, вручную, при остановке и при выходе.

Долгосрочное общение выключено по умолчанию. Пока оно выключено, диалоги существуют только в памяти процесса. После явного включения отправленные сообщения, ответы и технические provider/model/fact IDs сохраняются локально в `%LocalAppData%\GtaRpAssistant\assistant-data.db`. Выключение прекращает использование постоянной истории, но не удаляет файл; удаление отдельных диалогов выполняется пользователем с подтверждением.

`assistant-data.db` отделена от `knowledge.db`. История пользователя не становится официальной базой знаний.

Кэш ответов подчиняется тому же переключателю долгосрочного общения. Пока сохранение истории выключено, кэш ограничен памятью процесса и исчезает при закрытии приложения. После включения проверенные ответы могут храниться в таблице `answer_cache` внутри `assistant-data.db`: исходный вопрос не записывается, вместо него используется SHA-256 ключ, зависящий от сервера, ревизии knowledge facts и персонализации. Хранятся только ответы с решением `show`, уже прошедшие grounding validator; лимит — 1000 записей, TTL — 7 дней. Выключение долгосрочного общения немедленно прекращает чтение и запись постоянного кэша, но не удаляет уже существующий локальный файл.

Подтверждённая пользователем память и профиль стиля хранятся отдельно в `%LocalAppData%\GtaRpAssistant\user-memory.db`. Записи создаются и редактируются пользователем на странице «Память»; их можно удалить по одной или очистить полностью. Они передаются только локальной AI-модели и никогда не включаются в запрос облачного provider. Verified facts, server scope и решение grounded validator формируются независимо от User Memory.

Structured session state и rolling summary длинного разговора существуют только в RAM и очищаются вместе с контекстом или при создании нового диалога. Они считаются частным недоверенным контекстом: отправляются только локальной модели и никогда не включаются в cloud request. Полная история не копируется в summary и не передаётся модели целиком.

Постепенная адаптация стиля выключена по умолчанию. После явного включения она реагирует только на прямые просьбы вроде «отвечай короче» или «без шуток». Исходный текст реплики не сохраняется: журнал содержит только изменённый параметр, старое/новое значение и понятную причину. Профиль и журнал можно сбросить через UI. Game audio не используется для адаптации.

Облако выключено до явного разрешения. Отправка game audio в облачный STT имеет отдельное разрешение. Перед vision-запросом пользователь видит точный снимок и тип endpoint; после ответа массив изображения очищается.

Semantic rerank принимает только локальный loopback embedding endpoint. Ему передаются текущий вопрос и короткие тексты уже найденных статей; облачный embedding fallback не используется. До 128 векторов документов могут временно кэшироваться только в RAM и исчезают при закрытии приложения или смене настройки.

Embedded `whisper.cpp` STT работает только на случайном loopback-порту. PCM-сегмент передаётся локальному дочернему процессу в памяти и не сохраняется приложением на диск. Отсутствие или ошибка optional pack не включает облако автоматически.

Логи содержат только события, состояния, типы ошибок и агрегированные размеры. Текст разговоров, аудио, ключи, полный model request и полный model response не журналируются. Ротация: до пяти файлов по 2 МБ.

Пользователь видит состояния микрофона, GTA audio, локальной обработки и паузы. Полная пауза останавливает аудиосессию и TTS.
# Автоматическое понимание экрана

Локальное наблюдение за экраном выключено по умолчанию и захватывает только окно найденного процесса GTA. Уменьшенные кадры сравниваются в памяти; полный кадр создаётся только после заметного изменения, используется локальным OCR и очищается. Кадры не записываются на диск. OCR-текст хранится во временном контексте с TTL и не передаётся Chat/Vision-провайдерам. Явный вопрос об экране обслуживается локальным детерминированным обработчиком; очистка временного контекста удаляет также последнее screen-наблюдение.

Выбранные пользователем через кнопку **Фото** PNG/JPEG имеют более строгую границу: только локальный Vision provider, без cloud fallback. Перед анализом показывается preview; файл ограничен 12 МБ и 33 Мп, нормализуется во временный PNG, а оба byte-buffer очищаются после запроса. Общее разрешение cloud не считается согласием на отправку файла.
