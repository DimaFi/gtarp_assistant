# Локальное понимание экрана

Подсистема наблюдает только окно найденного процесса GTA и по умолчанию выключена. Она не читает память процесса, не перехватывает ввод и не управляет игрой.

## Pipeline

`WindowCaptureService` создаёт уменьшенный grayscale-кадр (320 px по ширине). `GridScreenFrameDiffer` сравнивает его с предыдущим кадром и разбивает изменения на сетку 8×6. Полный PNG создаётся только при превышении порога изменения, передаётся локальному OCR и очищается из памяти после обработки.

`TesseractScreenOcr` запускает установленный локально `tesseract.exe` с `rus+eng`. Исполняемый файл ищется в `PATH`; явный путь задаётся переменной `GTA_RP_TESSERACT_PATH`. Если OCR отсутствует, наблюдатель продолжает дешёвый frame diff без генерации контекста.

`KnownScreenRecognizer` классифицирует Shop, Inventory, Quest и Dialog по локальным текстовым якорям. `ScreenFieldProfiler` применяет ROI-профиль известного окна и назначает полям роли: title, price, item, details, objective, dialogue, button. Результат сохраняется в `ScreenContextStore` на 20 секунд по умолчанию. Изображения на диск не записываются.

Явные вопросы «что написано на экране?», «какая цена?» и аналогичные обслуживаются локальным deterministic-путём до поиска знаний и provider routing. Ответ содержит только свежие OCR-наблюдения, не получает fact IDs, не озвучивается и маркируется как не являющийся источником игровых правил. При отсутствии свежего контекста работает обычный безопасный answer pipeline.

## Privacy boundary

OCR-текст считается недоверенным наблюдением, а не источником игровых правил. Он не добавляется в Chat/Vision provider requests: существующее разрешение облачного Chat не является согласием на передачу содержимого экрана. URLs, управляющие и bidi-символы очищаются перед показом. Для будущей provider-интеграции нужен отдельный consent или гарантированно локальный маршрут.

## Настройки

- `Off` — захват отсутствует;
- `EventTriggered` — проверка примерно раз в 1,5 секунды;
- `LowFrequency` — интервал 0,5–5 секунд, стандартно 1 секунда;
- порог изменившихся пикселей — 1,5%;
- TTL текстового контекста — 5–60 секунд.
