# Model license records

Здесь хранятся только review-записи и обязательные notices для конкретных, прошедших benchmark артефактов. Веса моделей и непроверенные копии лицензий в репозиторий не добавляются.

Перед поставкой model pack обязательны:

1. точные `model id`, revision/commit и SHA-256 исходных весов;
2. происхождение и SHA-256 GGUF;
3. лицензия исходной модели и runtime;
4. commercial use, fine-tuning и redistribution review;
5. требуемые attribution, Notice и use restrictions;
6. ссылка на подписанный ADR и benchmark report.

Текущий технический review кандидатов описан в [`docs/MICRO_MODEL_BENCHMARK.md`](../../docs/MICRO_MODEL_BENCHMARK.md). Он не является юридическим заключением и не разрешает автоматически включать веса в релиз.
